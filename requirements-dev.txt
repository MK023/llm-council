# Dev dependencies — the only supply chain this project actually has.
#
# The runtime is stdlib-only, so the README's "zero dependencies" holds. But CI
# pulls these three from PyPI on every run, and until 2026-08-13 it pulled them
# pinned by VERSION only: a version pin trusts PyPI to keep serving the same
# bytes under that name. The hash pin does not.
#
# Regenerate after a version bump (hashes come from the PyPI JSON API, so this
# never gets typed by hand):
#   python scripts/pin_dev_deps.py ruff==X.Y.Z coverage==X.Y.Z zizmor==X.Y.Z > requirements-dev.txt
#
# Install with (the flag is the gate — without it the hashes are decoration):
#   pip install --require-hashes -r requirements-dev.txt
#
# Wheels covered: py3-none-any, manylinux x86_64 (CI and, since 2026-09-04, the
# development machine too — Ubuntu 26.04), macOS arm64 + x86_64. The macOS hashes
# are kept although nothing installs from them today: dropping them is a one-line
# regeneration, and re-adding them is a lockfile that fails on the first Mac.
# None of the three has a runtime dependency of its own, so this list is complete.
